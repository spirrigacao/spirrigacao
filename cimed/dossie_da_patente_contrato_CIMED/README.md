# Portal de Apresentação Corporativa - Patente Tampa Híbrida 10 mL (CIMED)

Página de apresentação oficial da **Patente BR 20 2026 029451 4** para a diretoria e jurídico da **CIMED INDÚSTRIA S.A.**.

## Documentos Disponibilizados:
1. **Dossiê Técnico INPI:** Pedido de Patente de Modelo de Utilidade nº `BR 20 2026 029451 4` (Protocolo nº `875260000560`, depositado em 19/11/2026), com 19 páginas de especificações técnicas, reivindicações e pranchas de engenharia.
2. **Minuta Contratual CIMED:** Contrato de Licenciamento Exclusivo de Patente, Tecnologia Industrial e Exploração Comercial (PDF e DOCX editável).

## Como Publicar no GitHub Pages:
1. No terminal dentro desta pasta:
   ```bash
   git init
   git add .
   git commit -m "Publicação do portal oficial de patente e contrato CIMED"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```
2. No repositório no GitHub:
   - Vá em **Settings** > **Pages**
   - Em **Branch**, selecione `main` e a pasta `/ (root)`
   - Clique em **Save**. O site estará no ar em poucos segundos!
